### 1.4 能力分级口径（依据 GB/T 42195-2022，权威）

> 本节为国标口径的落地。PRD 其余章节文案与本节不一致时，**以本节（国标）为准**。

**① 评估维度与满分（4 维度 / 26 项二级指标 / 合计 90 分）**

| 维度码 | 一级指标 | 二级指标数 | 满分 |
|---|---|:--:|:--:|
| D1 | 自理能力 | 8 | 32 |
| D2 | 基础运动能力 | 4 | 15 |
| D3 | **精神状态** | 9 | 28 |
| D4 | 感知觉与社会参与 | 5 | 15 |
| — | **合计** | **26** | **90** |

**② 能力等级阈值（5 级）**

| 等级码 | 等级名称 | 总分区间 |
|---|---|---|
| L0 | 能力完好 | 90 |
| L1 | 能力轻度受损（轻度失能） | 66–89 |
| L2 | 能力中度受损（中度失能） | 46–65 |
| L3 | 能力重度受损（重度失能） | 30–45 |
| L4 | 能力完全丧失（完全失能） | 0–29 |

**③ 特殊规则（国标表 6）**

- **直判（优先级最高）**：处于昏迷状态 → 直接判 **L4**；意识状态改变应重新评估。
- **升级**：命中任一情形，在原有等级上**提高一个级别**（不叠加、封顶 L4）——① 确诊痴呆（ICD-10 F00–F03）；② 精神科专科医生诊断的其他精神和行为障碍（F04–F99）；③ 近 **30 天**内发生 **≥2 次**照护风险事件（跌倒 / 噎食 / 自杀 / 自伤 / 走失等）。

**④ 拒答口径**

- 老人拒答的指标项：**记 0 分、分母（满分 90）不缩水**，并触发人工复核（见 §4.3）。

> 报告须同时展示 **初判等级**（仅按总分）与 **终判等级**（叠加特殊规则）；二者不一致时输出"等级变化原因"，并绑定判定所用规则版本号以支持事后复算。

## 4 核心业务流程

### 4.1 流程 A · 老年人能力评估主流程（P0 核心链路）

```
① 创建评估 → ② 指标采集 → ③ 引擎分级 → ④ 生成报告 → ⑤ 提交复核 → ⑥ 复核发布 → ⑦ 家属触达
   选择老人        26 项·4 维度     规则计算        PDF+二维码      录入人提交      通过/驳回      推送+订阅
   校验资质        自适应+留证      输出等级        草稿态          互斥校验        管理员复核      照护建议
```

### 4.2 流程 B · 家属亲情绑定流程（P1）

```
① 家属发起 → ② 身份核验 → ③ 老人确认 → ④ 机构审核 → ⑤ 授权生效
   扫码/手机号    实名+人脸      本人同意      管理员复核     设置有效期
   填写关系       关系证明       监护人代确认   绑定关系      到期自动失效
```

### 4.3 异常分支 · 评估流程
| 异常场景 | 触发条件 | 处理方式 |
|---|---|---|
| 资质失效 | 评估员证书过期 | 阻断创建，提示续期 |
| 重复评估 | 30 天内已评估 | 提示确认，强制填写变更原因 |
| 老人拒答 | 被评估人拒绝 | 标记"拒绝回答"，该项**记 0 分、分母（满分 90）不缩水**，触发人工复核（见 §1.4④） |
| 指标缺失 | 必填项未填 | 阻断提交，定位到缺失项 |
| 复核驳回 | 管理员驳回 | 退回录入人，保留意见，可修改再提交 |
| 断网离线 | 网络不可用 | 本地缓存，恢复后自动同步，冲突提示 |

### 4.4 状态机 · 评估单
| 状态 | 说明 | 可见范围 | 可操作性 |
|---|---|---|---|
| 草稿 | 录入中 | 仅本人 | 可编辑 |
| 待复核 | 已提交，锁定 | 本人 + 管理员 | 只读 |
| 已发布 | 复核通过 | 全角色（含家属） | 只读，可导出 |
| 已驳回 | 退回录入人 | 本人 + 管理员 | 可修改重提 |
| 已作废 | 管理员作废 | 仅审计 | 保留审计记录 |
| 归档 | 超保留期 | 仅监管 | 只读 |

## 7 全局交互规则

| 规则 | 标准 |
|---|---|
| 🎨 适老化基线 | 正文 ≥16px，题干 ≥20px；触控区 ≥88×88px；对比度 ≥4.5:1；支持系统大字模式 |
| 🔊 语音辅助 | 题干支持 TTS 播报，语速可调；关键操作支持语音确认 |
| 💾 自动保存 | 问卷 30s 自动存草稿；页面切换/断网立即保存；恢复时提示续填 |
| 🔒 敏感操作 | 导出/删除/作废/解绑 需二次确认 + 短信/人脸验证，全程留痕 |
| ⏱ 超时处理 | 请求 >3s 显示 loading；>10s 提示"网络较慢"；失败提供重试按钮 |
| 📴 离线策略 | 问卷/档案支持离线；顶部显示离线标识；联网后自动同步并提示冲突 |
| ⚠️ 错误提示 | 表单校验就近提示；全局错误用 Toast；阻断性错误用 Dialog + 跳转定位 |
| 🔁 幂等防重 | 提交按钮点击后立即置灰；网络重试带幂等 Key；防重复生成报告 |
| 🅰 空状态 | 所有列表/搜索必须有空状态插画 + 引导文案 + 主操作按钮 |
| 🔐 隐私展示 | 身份证/手机号/健康信息默认脱敏（如 138****5678），点击"查看"需验证 |
| 🚫 权限拦截 | 无权限不显示入口；直接访问 URL/接口返回 403 + 无权限页 |
| 🧭 返回逻辑 | 问卷页返回需二次确认；表单有改动返回提示"是否保存草稿" |

## 8 四端差异化说明

| 差异项 | 微信小程序 | 抖音小程序 | iOS App | 安卓 App |
|---|---|---|---|---|
| **产品定位** | 家属主入口 + 评估员轻量 | 获客引流 + 科普内容 | 评估员/机构深度使用 | 评估员/机构/监管 |
| **功能范围** | 报告查看、绑定、消息<br>（评估录入受限） | 科普、机构展示、预约<br>（不做评估录入） | 全功能 + 离线 + 外设 | 全功能 + 离线 + 批量导出 |
| **登录方式** | 微信授权 + 手机号 | 抖音授权 + 手机号 | 账号密码 / Apple ID / Face ID | 账号密码 / 指纹 / 面容 |
| **消息触达** | 订阅消息（需授权） | 站内信 + 抖音通知 | APNs 推送 | 厂商通道（小米/华为等） |
| **支付** | 微信支付 | 抖音支付 | IAP（虚拟）/ 三方（实物） | 微信 + 支付宝 + 银联 |
| **离线能力** | 弱（仅本地缓存） | 弱 | 强（本地 DB + 同步队列） | 强（本地 DB + 同步队列） |
| **生物识别** | 微信实名 + 活体 | 抖音实名 | Face ID / Touch ID | 指纹 / 面容（厂商适配） |
| **文件导出** | 分享 / 保存到聊天 | 不支持 | 系统分享面板 | 本地存储 + 分享 |
| **包体限制** | ≤2MB（主包） | ≤4MB | 无硬限（建议 <150MB） | 无硬限（建议 <100MB） |
| **合规要点** | 隐私弹窗前置、类目资质 | 内容审核、敏感词过滤 | Privacy Manifest、ATT | 权限最小化、个保法弹窗 |
| **适配单位** | rpx（750 基准） | rpx（750 基准） | pt（@1x/@2x/@3x） | dp（mdpi→xxxhdpi） |
| **适配机型** | 微信 8.0+ | 抖音 20.0+ | iOS 14+ / iPhone 8 起 | Android 9+ / 50+ 机型 |

**统一原则**：
- 业务模型、API、状态机、文案**四端完全一致**，由后端统一供给
- 差异仅在：导航形态、平台能力、审核合规、视觉微调
- 跨端技术选型：UniApp / Taro 覆盖双小程序；iOS/安卓原生补齐深度能力

## 9 数据埋点需求

| 序 | 事件名 | 触发时机 | 关键参数 | 端 | 业务用途 |
|---|---|---|---|:--:|---|
| 1 | `assessment_create` | 点击"新建评估" | 老人ID、场景、评估员ID、机构ID | 四端 | 评估量统计 |
| 2 | `assessment_item_answer` | 每项指标作答 | 指标ID、维度、分值、耗时、是否留证 | 四端 | 题目难度/耗时分析 |
| 3 | `assessment_submit` | 提交复核 | 评估单ID、总分、等级、耗时 | 四端 | 转化漏斗 |
| 4 | `report_view` | 查看报告 | 报告ID、查看角色、来源 | 四端 | 报告触达率 |
| 5 | `report_export` | 导出/下载 | 报告ID、格式、导出人、脱敏级别 | App/Web | 合规审计 **必留痕** |
| 6 | `bind_relative` | 亲情绑定提交 | 关系、核验方式、是否成功 | 小程序 | 绑定转化率 |

**埋点合规约束**：
- 禁止采集：身份证全文、人脸原始图像、健康明细（埋点仅传 ID 与枚举值）
- 老人端埋点需家属或本人授权，未授权不采集
- 所有埋点数据脱敏后入库，保留期 ≤180 天
