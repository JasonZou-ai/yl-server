## 1 主体一致性核对（★ 驳回重来的第一大原因）

| 项 | 要求 | 状态 |
|---|---|---|
| 营业执照 | 经营范围含技术服务/软件信息服务 | ⬜ 需主体方提供原件扫描件 |
| 小程序主体 | 微信/抖音小程序注册主体须与短信签名主体**一致** | ⬜ 需核对小程序认证信息 |
| 签名主体 | `【银龄守护】` 签名归属主体须与上两者一致 | ⬜ 不一致时先改签名再报备 |

## 2 B1 服务商账号开通（主：腾讯云 SMS；备：阿里云 SMS）

| 材料/动作 | 说明 | 状态 |
|---|---|---|
| 服务商控制台账号 | 实名认证完成（企业主体） | ⬜ |
| 开通 SMS 服务 | 领取 **AppId**（腾讯云）/ 短信签名、模板入口 | ⬜ |
| 付费方式确认 | 按量计费，先小额充值验证通道 | ⬜ |

## 3 B2 签名报备（`【银龄守护】`）

| 材料 | 要求 | 状态 |
|---|---|---|
| 签名内容 | `银龄守护`（4 字，与小程序名称一致最稳） | ⬜ |
| 签名用途说明 | 「登录/绑定验证码下发」**仅验证码用途**（呼应 B5：不发营销） | ⬜ |
| 资质证明 | 营业执照 + 小程序备案/认证截图（证明签名归属） | ⬜ |
| 备案回执 | 平台审核通过截图/邮件 → **归档 docs/change/**（B4，同 DPO-Signoff 体例） | ⬜ |

## 4 B3 模板报备（登录验证码）

| 材料 | 要求 | 状态 |
|---|---|---|
| 模板类型 | 普通短信 · 验证码类 | ⬜ |
| 模板内容 | `您的验证码为{1}，{2}分钟内有效。请勿泄露给他人。`（与代码变量位序一致——**报备前须与 `SmsCodeService` 实际下发文案逐字核对**） | ⬜ |
| 变量口径 | `{1}=验证码 {2}=有效分钟数`（与现有实现一致） | ⬜ |
| 模板 ID + 回执 | 审核通过后归档（B4） | ⬜ |

## 5 B5/B6 合规与安全随行项（开通同批做，不单独排期）

| 项 | 口径 | 状态 |
|---|---|---|
| B5 用途限定 | 通道配置**仅验证码**，营销类模板一律不开 | ⬜ |
| B6 子账号最小权限 | 独立子账号仅授 SMS 发送权限；密钥走环境变量（`禁入库/禁硬编码`，沿用 P2-8-R9 教训） | ⬜ |
| B4 回执归档 | 签名/模板/AppId 三类回执统一入 `docs/change/`，体例同 `DPO-Signoff-*` | ⬜ |
