ER 三方评审（2026-09-18，结论「有条件通过」）对「本期范围（MVP）」作出**显式出清**裁决：

- **ER-02**：功能点 **21/22**（消息中心）、**23/24**（支付与合同）**全部移入 V2 需求池**；

  本期以「固定报表 + 异步导出（`export_task`）」承载。

   「2 待评审 / 5 待审 / 6 待走查 / 7 未开始」，与任务系统 M1 全 `done` 矛盾。
2. **任务侧**：C5 消息与触达、D7 支付与合同**已排入 M2**（W8–W11），但其功能点在 PRD 范围外、DDL 亦无对应表。
